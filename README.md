# dhimantbhardwaj.me

Static portfolio website for Dhimant Bhardwaj.

## Files
- `index.html` — portfolio content and structure
- `styles.css` — responsive visual design
- `script.js` — navigation + reveal animations
- `resume.pdf` — resume download

## Deploy with Cloudflare Pages
1. Create a new GitHub repository and upload these files.
2. In Cloudflare Pages, connect the repository and deploy with no build command.
3. Set the output directory to `/` (the repository root).
4. Add `dhimantbhardwaj.me` as a custom domain in the Cloudflare Pages project.
5. At Namecheap, update DNS as instructed by Cloudflare for the custom domain.

## Deploy with GitHub Pages
1. Push these files to a GitHub repository.
2. Enable GitHub Pages from Settings → Pages → Deploy from branch.
3. In the repository Pages settings, set the custom domain to `dhimantbhardwaj.me`.
4. At Namecheap, create the DNS records GitHub provides for the custom domain.
